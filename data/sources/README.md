# База источников

Каждый файл `*.md` — один источник. В шапке (между `---`) указаны название,
ссылка, дата актуальности и пометка `is_demo`.

## Источники МУИТ (`iitu_*.md`) — база знаний «Спроси МУИТ»

Тексты пересказаны близко к официальным страницам iitu.edu.kz (путеводитель
студента, нормативно-правовая база, центр карьеры, библиотека, IITU International,
военная кафедра, студенческая жизнь, факультеты, контакты). В шапке дополнительно:

- `checked:` — дата, когда текст сверили со страницей (бот показывает её в ответе);
- `office:` — подразделение «куда идти» (id из `data/iitu/services.json`);
- `modes:` — в каких режимах источник используется (`vopros` — «Спроси МУИТ»).

Правила:
1. Только факты со страницы по ссылке `url`. Не нашли на странице — не пишем.
2. Реквизиты оплаты и стоимость в текст источника НЕ включаем — бот даёт ссылку на страницу.
3. Обновили страницу — обновите текст и `checked`.
4. Академический календарь хранится отдельно — `data/iitu/calendar_*.json`
   (даты переносятся из PDF со страницы календаря) и подключается к поиску автоматически.
5. Свежие новости МУИТ подключаются к поиску режима «Правда?» автоматически из кэша ленты.

## Демо-источники (`is_demo: true`)

Файлы `demo_*.md` — **примерные тексты для демонстрации**. Они написаны
по мотивам типичных ситуаций и общеизвестных правил безопасности, но
**не являются нормами права** и не цитируют законы. Карточки, которые на
них ссылаются, помечаются «[ДЕМО]». Номера статей в них намеренно не указаны.

## Как добавить настоящий источник

1. Найдите официальный текст: adilet.zan.kz (законы), egov.kz, сайты госорганов
   (gov.kz), nationalbank.kz, stat.gov.kz.
2. Запустите скрипт — он скачает страницу, уберёт оформление и сохранит
   источник с сегодняшней датой:
   ```
   .venv\Scripts\python scripts\fetch_source.py https://www.gov.kz/... --modes prava,chek --keywords "возврат, товар"
   ```
   **adilet.zan.kz** подгружает текст законов скриптом, и скрипт его не увидит.
   Для него скопируйте текст закона из браузера в файл `law.txt` (UTF-8) и добавьте
   `--from-file law.txt --title "Закон РК «…»"`.
3. Проверьте файл глазами: нужные ли куски попали, верно ли название.
4. Перезапустите сервер.

Скрипт принимает только официальные домены (список — в `scripts/fetch_source.py`).
