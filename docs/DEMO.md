# Сценарий показа (10 минут)

**Подготовка**
1. `run.bat` → сервер запущен, бот подключён (в консоли «Бот @… подключён»).
2. Для показа Mini App в Telegram — туннель и `WEBAPP_URL` (README → «Mini App внутри Telegram»),
   `DEV_MODE=false`. Для показа в браузере — `DEV_MODE=true` и задача «Демо-данные».
3. Создайте группу «Семья (демо)», добавьте бота и второй аккаунт (или попросите знакомого).
4. Второй человек: открыть бота, `/start`. Вы: Mini App → «Семья» → «Создать семью» →
   отправить приглашение второму человеку → он вступает.

**1. «Ваша карта заблокирована» (2 мин)**
- В группе кто-то пишет: *«Kaspi Bank: ваша карта заблокирована! Служба безопасности.
  Срочно назовите код из SMS: https://kaspi-secure.top/login»*.
- Ответьте на это сообщение командой `/razvod`.
- Покажите: 🔴, подсвеченные фразы, разбор ссылки («kaspi» в чужом домене, зона .top),
  «что делать / чего не делать», кнопки 👍/👎, «Переслать карточкой» (картинка), «Объяснить проще».
- Близкому из «Семьи» приходит уведомление 🔔.

**2. Фейк про «новый закон» (1 мин)**
- `/pravda С понедельника вводят штраф за голосовые сообщения в общих чатах WhatsApp! Разошлите всем!`
- 🔴 с источником и датой актуальности. Обратите внимание на пометку [ДЕМО] — честность.
- Контраст: `/pravda В Шымкенте с завтрашнего дня бесплатный проезд для всех школьников` → ⚪
  «недостаточно данных» — бот не выдумывает.

**3. Mini App (2 мин)**
- Главная: иммунитет, серия дней, «Что проверить?».
- История проверок → карточка с подсветкой.
- Проверка дня → ответить → разбор и серия.

**4. Тренажёр (2 мин)**
- Тренажёр → «Служба безопасности банка».
- Ответить: «Кто вы? Я сам перезвоню в банк» → «Нет, код не скажу».
- Разбор: иммунитет %, приёмы мошенника, советы. Повторить и «поддаться» — увидеть разницу.

**5. Договорились (2 мин)**
- В группе: `/dogovorilis Аскар отдаёт Марату 20 000 ₸ до 15 октября`.
- Второй человек нажимает «✅ Подтверждаю» (автор сам себе подтвердить не может).
- «📄 PDF» → протокол. Оговорка: это фиксация переписки, а не договор.
- Накануне срока бот напомнит.
