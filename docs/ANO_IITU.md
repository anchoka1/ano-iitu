# ANO IITU — университетская версия «Вердикта» для МУИТ

Бот-«вердикт» студенческого сообщества Международного университета информационных
технологий (МУИТ / IITU, Алматы). Ядро — проект «Вердикт»: проверка, развод, спор,
договорились, чек, права. Всё, что умел «Вердикт», работает по-прежнему; добавлены
университетская среда, база знаний из официальных источников, новости, навигатор по курсам
и Mini App в стиле сайта iitu.edu.kz.

**Как бот называет себя:** «бот для студентов и преподавателей МУИТ». В Mini App используется
фирменный стиль и логотип МУИТ (файлы с iitu.edu.kz в `miniapp/img/`). На вопрос «это официальный
бот?» бот отвечает по существу: информацию он берёт с сайта университета и показывает источник,
а официальные решения принимают деканат и другие подразделения.

**Идея «Адал қоғам» — честное общество.** Бот продвигает академическую честность и
нетерпимость к обману: «проверь, прежде чем верить и пересылать»; распознаёт продажу
«ответов» и «оценок», фейковые сборы и поддельные реквизиты; объясняет Кодекс академической
честности МУИТ и подсказывает ящик доверия; отвечает только по официальным источникам и
честно говорит «не знаю».

## 3. Экран «О боте» (Mini App)

- **/01 Что это.** ANO IITU — бот-«вердикт» студенческого сообщества МУИТ. Помогает отличать
  правду от слухов, не попадаться на разводы, фиксировать договорённости и знать свои права.
  Честность — не лозунг, а привычка: «проверь, прежде чем верить и пересылать».
- **/02 Что умеет.** Проверяет слухи по академическому календарю и новостям МУИТ ·
  распознаёт мошенничество вокруг студентов · фиксирует договорённости с подтверждением
  участников · разбирает споры без «кто прав» · отвечает о правилах МУИТ только по базе
  знаний · показывает новости, навигатор по курсам и куда идти.
- **/03 Откуда информация.** Только официальные источники: страницы iitu.edu.kz,
  новости сайта и Telegram-канал @iitu_channel. У каждого ответа — ссылка и дата проверки.
  Нет ответа — «не знаю» и подразделение, куда обратиться.
- **/04 Чего не делает.** Не заменяет деканат, Офис-регистратор и юриста; не принимает
  решений и не ставит оценок; не пересказывает реквизиты оплаты; не спрашивает ИИН,
  документы и оценки; не помогает списывать.
- **/05 Кто я.** Бот для студентов и преподавателей МУИТ, сделан в рамках идеи «Адал қоғам» —
  честное общество начинается с честного кампуса. Решений за подразделения не принимает.
- **/06 Нашли ошибку?** Напишите боту /help или ответьте на карточку ссылкой на
  официальный источник (кнопка «➕ Источник»).

Тон — как у сайта: со студентами на «ты», энергично; с преподавателями — на «вы».

## 4. Как обновлять данные (без программирования)

| Что | Где | Как часто |
|---|---|---|
| Академический календарь | `data/iitu/calendar_2026_2027.json` | Каждый учебный год: перенести даты из PDF со страницы календаря, создать `calendar_2027_2028.json` |
| Навигатор по курсам | `data/iitu/navigator.json` | Когда меняются правила; у каждого пункта — `status` и `source` |
| Куда идти (контакты) | `data/iitu/services.json` | При изменении страницы «Контакты» |
| Факультеты, программы, кафедры | `data/iitu/reference.json` | При изменении страниц факультетов |
| Реквизиты для сверки (не показываются) | `data/iitu/requisites.json` | При изменении «Инструкции по оплате» |
| База знаний «Спроси МУИТ» | `data/sources/iitu_*.md` | При изменении страниц; обновить `checked` |
| Новости | автоматически, раз в `NEWS_REFRESH_MINUTES` | — |

После правки файлов перезапустите сервер.

## 5. Новые настройки (`.env`)

```
NEWS_ENABLED=true
NEWS_SITE_URL=https://iitu.edu.kz/ru/news/
NEWS_TELEGRAM_CHANNEL=iitu_channel
NEWS_REFRESH_MINUTES=60
NEWS_SUMMARY_PER_RUN=4
NEWS_NOTIFY_MAX=3
CALENDAR_REMIND_DAYS=2
```

## 6. Правила достоверности (в коде, их нельзя обойти текстом сообщения)

1. «Спроси МУИТ» отвечает только при найденном источнике; иначе ⚪ «не знаю» + подразделение.
2. Реквизиты (IBAN, БИН, номера карт), суммы и даты, которых нет во входном тексте или в
   найденных источниках, вырезаются из ответа и заменяются ссылкой на официальную страницу
   (`cards/rules.py → enforce_university`).
3. Кризисные сообщения (мысли о вреде себе, тревога, выгорание — о себе) получают не вердикт,
   а контакты психологической службы МУИТ и линий 150 / 111 (`university/crisis.py`).
4. Реквизиты «для оплаты обучения» из чатов сверяются с официальными
   (`university/requisites.py`); несовпадение — сильный признак 🔴.
5. Роль преподавателя — по самозаявлению и не даёт прав над студентами.
6. Новости: при недоступности источника показываем кэш с пометкой, а не пустоту и не выдумку;
   подписка на новости по умолчанию выключена.
