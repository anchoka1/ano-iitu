# ANO IITU — честный помощник студента МУИТ

Telegram-бот и Mini App для студентов и преподавателей Международного университета
информационных технологий (МУИТ / IITU, Алматы). ANO IITU проверяет
слухи, сообщения, ссылки, квитанции, договорённости и спорные ситуации и отвечает понятным
результатом проверки с источниками:
🟢 надёжно · 🟡 с оговорками · 🔴 опасно или ложно · ⚪ недостаточно данных.

Университетская версия добавляет роли (студент/преподаватель) и онбординг, базу знаний из
официальных источников iitu.edu.kz («Спроси МУИТ»), ленту новостей сайта и Telegram-канала
МУИТ, навигатор по курсам, академический календарь с напоминаниями, каталог «куда идти»,
блок для преподавателей, Mini App в стиле сайта университета. Идея — «Адал қоғам»:
честность и достоверность.

Бот представляется так: «бот для студентов и преподавателей МУИТ».
Тексты для BotFather, приветствия и экран «О боте», а также как обновлять данные — в
[docs/ANO_IITU.md](docs/ANO_IITU.md).

## Быстрый старт: что нужно сделать вам

1. **Запустить**: дважды щёлкните `run.bat` (или F5 в VS Code).
2. **Вставить бесплатный ключ ИИ** (Google Gemini):
   - зайдите на https://aistudio.google.com/apikey под Google-аккаунтом → «Create API key»;
   - откройте файл `.env`, впишите `LLM_API_KEY=ваш_ключ`, сохраните;
   - перезапустите `run.bat`. В консоли должно появиться «ИИ (gemini): Модель … доступна».
   - Бесплатно у основной модели Gemini ≈ 20 запросов в день, дальше бот сам переходит на облегчённую.
3. Всё. Без ключа работает **демо-режим**: карточки собираются по правилам, без ИИ.

Токен Telegram-бота уже лежит в `.env` (`TELEGRAM_BOT_TOKEN`).

## Запуск подробно (Windows)

Нужно: **Python 3.11+** ([python.org](https://www.python.org/downloads/), галочка «Add python.exe to PATH»).

1. Двойной щелчок по **`run.bat`**. Первый раз 1–3 минуты: скрипт сам создаст `.venv`,
   поставит библиотеки, создаст `.env` и базу `data/verdikt.db`.
2. Когда появится рамка «ANO IITU запущен», откройте **http://localhost:8000** — это Mini App.
3. Остановить: `Ctrl+C` в окне сервера.

**Демо-данные** (чтобы все экраны были заполнены): VS Code → `Ctrl+Shift+P` →
«Tasks: Run Task» → «Демо-данные», или
`.venv\Scripts\python scripts\seed_demo.py`.

### VS Code

1. **File → Open Folder** → папка `verdikt`; согласитесь установить расширения.
2. **F5** → «ANO IITU: сервер + бот». Если первый раз F5 ругается на `.venv` — запустите `run.bat` один раз.
3. Задачи (`Ctrl+Shift+P` → Tasks: Run Task): «Подготовка», «Запуск сервера и бота»,
   «Тесты», «Демо-данные», «Оценка качества (демо)», «Оценка качества (реальный ИИ, платно)».

### PowerShell, macOS, Linux

```powershell
.\run.ps1              # подготовить и запустить
.\run.ps1 -SetupOnly   # только подготовить
.\run.ps1 -Test        # тесты
```
```bash
chmod +x run.sh && ./run.sh      # --setup, --test
```

## Настройки (`.env`)

Все переменные с пояснениями — в `.env.example`. Главные:

| Переменная | По умолчанию | Что значит |
|---|---|---|
| `LLM_PROVIDER` | `gemini` | Какая модель: `gemini`, `groq`, `openrouter` (бесплатно), `ollama` (локально), `anthropic` (платно) |
| `LLM_API_KEY` | пусто | Ключ для gemini / groq / openrouter. Пусто — демо-режим |
| `LLM_MODEL` | пусто | Модель; пусто — по умолчанию для провайдера |
| `TELEGRAM_BOT_TOKEN` | пусто | Токен бота. Пусто — бот не запускается, сервер работает |
| `MOCK_LLM` | `auto` | `auto` — ИИ, если есть ключ; `true` — всегда демо; `false` — всегда ИИ |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | пусто / `claude-sonnet-5-5` | Только для `LLM_PROVIDER=anthropic` (платно) |
| `DEV_MODE` | `true` | Mini App в обычном браузере без подписи Telegram (только с этого компьютера) |
| `WEBAPP_URL` | пусто | HTTPS-адрес Mini App для Telegram |
| `LLM_DAILY_TOKENS_PER_USER` | `200000` | Дневной лимит токенов на человека |
| `CHECKS_PER_MINUTE` / `CHECKS_PER_DAY` | 6 / 100 | Антиспам |
| `OWNER_IDS` | пусто | Telegram id владельцев бота через запятую: модерация, подтверждение преподавателей и менторов |
| `ANON_SALT` | пусто | Соль для анонимных хешей; пусто — сгенерируется и сохранится в базе |
| `ANON_MIN_ANSWERS` | `5` | Сколько ответов нужно, чтобы показать результат анонимного опроса |
| `FEATURE_<КЛЮЧ>` | `true` | Включить/выключить новую функцию (список — в конце `.env.example`) |

> `.env` содержит секреты и **не попадает в git**. Если токен бота утёк:
> @BotFather → `/revoke` → новый токен в `.env`.

### Бесплатные модели

| Провайдер | Где взять ключ | Модель по умолчанию | Особенности |
|---|---|---|---|
| **gemini** (рекомендуется) | https://aistudio.google.com/apikey | `gemini-flash-latest`, запасная `gemini-flash-lite-latest` | Хороший русский, понимает фото. **Основная модель — около 20 запросов в день бесплатно**; когда они кончаются (или модель перегружена), бот сам переходит на lite с отдельным лимитом |
| **groq** | https://console.groq.com/keys | `openai/gpt-oss-120b` | Очень быстрый; фото читает `qwen/qwen3.8-27b`, голосовые — Whisper |
| **openrouter** | https://openrouter.ai/keys | `meta-llama/llama-3.3-70b-instruct:free` | Много бесплатных моделей с пометкой `:free` |
| **ollama** | ключ не нужен | `qwen2.5:7b` | Полностью офлайн, но нужно 16+ ГБ памяти; на 8 ГБ — 1–3 минуты на проверку |

Чтобы сменить: `LLM_PROVIDER=groq` и `LLM_API_KEY=ключ_groq` в `.env`, перезапуск.
При запуске сервер проверяет, что ключ подходит и модель существует; если модели нет —
показывает в консоли список доступных.

**Честно о бесплатных тарифах:**
- есть лимиты запросов в минуту и в день — при превышении бот вежливо попросит подождать;
- на бесплатных тарифах провайдер **может использовать присланные тексты для улучшения
  своих моделей** — учитывайте это, если проверяете сообщения с личными данными;
- PDF облачные бесплатные модели в этом проекте не читают — присылайте фото документа;
- качество разных моделей отличается; сравнить можно задачей «Оценка качества (реальный ИИ)».

Лимит на человека в день задаёт `LLM_DAILY_TOKENS_PER_USER`. Повторная проверка того же
текста берётся из кэша — без запроса к ИИ.

## Бот в Telegram

Бот работает через long polling: туннель и webhook не нужны. Описание, короткое описание
и меню команд бот выставляет **сам** при запуске из `backend/app/i18n/locales/ru.json`.
Вручную в @BotFather:

- **Аватарка**: `/setuserpic`.
- **Inline-режим** больше не используется: в `/setinline` его можно выключить.
- **Группы**: добавьте бота в чат. Режим приватности оставьте включённым — бот видит
  только команды, упоминания и ответы ему. В группе проверка идёт **ответом командой**
  на нужное сообщение: ответить → `/razvod`.
- **Реакции 👍/👎 как голоса**: Telegram присылает их боту, только если он **администратор** группы.

**Команды латиницей.** Telegram разрешает в командах только латиницу, цифры и `_`,
поэтому `/pravda`, а не `/правда`. Русские названия видны в меню.

**Ограничение Telegram.** Бот не может написать человеку первым, пока тот не нажал «Старт».
Поэтому уведомления «Семьи», напоминания и «Проверка дня» получают только те, кто открывал бота.

### Голосовые сообщения

Языковые модели проекта не принимают аудио. Чтобы бот понимал голосовые, установите локальное
распознавание речи (≈ 500 МБ, работает без интернета):

```
.venv\Scripts\pip install faster-whisper
```

и перезапустите. Без него бот честно отвечает, что голосовые не распознаёт.

## Mini App внутри Telegram

Telegram открывает Mini App только по **HTTPS**, а сервер работает на `http://localhost`.
Нужен туннель — публичный HTTPS-адрес, ведущий на ваш компьютер.

### Автоматически (включено по умолчанию)

В `.env` стоит `TUNNEL=cloudflare`. При запуске `run.bat` сервер сам:
1. скачивает официальную программу `cloudflared` в папку `tools/` (≈ 60 МБ, один раз, без регистрации);
2. поднимает бесплатный туннель и получает адрес `https://слова.trycloudflare.com`;
3. подставляет его в кнопки бота и ставит **кнопку меню** «ANO IITU» слева от поля ввода.

Адрес виден в консоли: `HTTPS-туннель готов. Mini App в Telegram: https://...`.
Открыть Mini App: кнопка меню «Вердикт» в чате с ботом или `/start` → «📱 Открыть приложение».
Если кнопка меню не появилась — полностью закройте и снова откройте Telegram (клиент кэширует её).

**Ограничения бесплатного туннеля:** адрес меняется при каждом запуске (бот обновляет кнопки
сам), работает, только пока включён компьютер с сервером, и не гарантирует стабильность.
Для постоянной работы нужен хостинг или свой домен (Cloudflare named tunnel).

### Вручную (если автоматический не подходит)

Поставьте `TUNNEL=` (пусто), запустите туннель сами (`cloudflared tunnel --url http://localhost:8000`
или `ngrok http 8000`) и впишите адрес в `.env`: `WEBAPP_URL=https://...`. Перезапустите сервер.

### Ссылка на Mini App для групп

Кнопки `web_app` в группах Telegram не разрешает. Чтобы под карточкой в группе была ссылка
`t.me/бот/имя?startapp=check_ID`: @BotFather → `/newapp` → бот → название, описание,
картинка 640×360, адрес, короткое имя → впишите имя в `.env`: `WEBAPP_SHORT_NAME=...`.
Учтите: в `/newapp` вписывается конкретный адрес, а у бесплатного туннеля он меняется —
это имеет смысл с постоянным адресом.

### Безопасность

Внутри Telegram сервер **всегда** проверяет подпись `initData` (HMAC по токену бота) и
свежесть `auth_date`. Запросы через туннель **не** получают «тестового пользователя» даже при
`DEV_MODE=true` (туннель добавляет заголовки прокси) — проверено: `/api/me` через туннель без
подписи отвечает 401. В браузере на этом компьютере (http://localhost:8000) режим разработки
продолжает работать.

## Источники и честность

- Бот ссылается **только** на тексты из `data/sources/`. Ссылки, которые «придумала» модель,
  код выбрасывает. Цитаты, которых нет в исходном тексте, тоже.
- Нет источника для `/pravda` → ⚪ «недостаточно данных». Уверенность ниже 40% → ⚪.
- **Сейчас в базе только демо-источники** с пометкой [ДЕМО]: это примерные тексты, не
  реальные нормы и без номеров статей. Добавить настоящие: `data/sources/README.md` и
  `scripts/fetch_source.py`. Для adilet.zan.kz текст нужно скопировать в файл (сайт подгружает его скриптом).
- Пересланный текст — **данные, а не инструкции** (защита от prompt injection; есть тесты).
- Ссылки анализируются **без открытия**: по адресу и реестру доменов (RDAP).
- Запрещена помощь в слежке за людьми.
- Приватность: телефоны, карты и ИИН маскируются в логах; `/delete` и кнопка в профиле
  удаляют всё; экспорт данных — в профиле.
- «Вердикт» **не заменяет юриста**.

## Частые ошибки

| Что видно | Что делать |
|---|---|
| `Не найден Python 3.11+` | Установите Python с галочкой «Add to PATH», перезапустите `run.bat` |
| Окно `run.bat` сразу закрывается | Запустите `run.bat` из терминала, чтобы увидеть ошибку |
| `running scripts is disabled` | Запускайте `run.bat`: он обходит запрет только для этого запуска |
| `[Errno 10048]` / порт занят | Сервер уже запущен в другом окне — закройте его или смените `PORT` |
| `Telegram-бот НЕ запущен` | Нет токена в `.env` — см. «Бот в Telegram» |
| `Telegram отверг токен` | Токен неполный или перевыпущен — возьмите актуальный в @BotFather |
| `Нет связи с Telegram` | Интернет/VPN. Первое подключение бывает долгим (до 30 с) |
| Бот не отвечает | Возможно, бот запущен ещё где-то с тем же токеном. Оставьте один процесс |
| `Ключ LLM_API_KEY не подошёл` | Проверьте ключ в `.env`: без пробелов и кавычек; ключ от того же провайдера, что в `LLM_PROVIDER` |
| `Модели «…» нет у gemini` | Впишите в `LLM_MODEL` одну из моделей, которые сервер перечислил в консоли |
| `Бесплатный лимит запросов исчерпан` | Подождите минуту (или до завтра) либо смените провайдера (`LLM_PROVIDER=groq`) |
| `Gemini недоступен в вашем регионе` / нет связи | Попробуйте `groq` или `openrouter`, либо VPN |
| Карточки с пометкой «Демо-режим» при вставленном ключе | Ключ не в той строке (нужен `LLM_API_KEY`) или `MOCK_LLM=true` — поставьте `auto`, перезапустите |
| Mini App: «Откройте приложение через Telegram» | `DEV_MODE=false` при открытии в браузере. Для локального просмотра — `true` |
| Mini App в Telegram: «Подпись Telegram не совпала» | Токен на сервере не от того бота, через которого открыто приложение |
| Голосовые не распознаются | Установите `faster-whisper` (см. «Голосовые сообщения») |
| Кракозябры в консоли | Запускайте через `run.bat`/`run.ps1`/F5 — они включают UTF-8 |
