# Оценка качества

`messages.jsonl` — 58 тестовых сообщений на русском (Казахстан): мошенничество
(банк, «родственник в беде», инвестиции, работа, OLX, eGov), фейки и «новые законы»,
квитанции и штрафы, споры, резкие сообщения, бытовые права, попытки prompt injection.

У каждого сообщения — `expected`: какой статус был бы правильным
(`green` / `yellow` / `red` / `unknown`).

```
.venv\Scripts\python evals\run_eval.py --mock     # демо-режим, бесплатно
.venv\Scripts\python evals\run_eval.py            # как в .env (с ключом — реальный ИИ, платно)
.venv\Scripts\python evals\run_eval.py --mode razvod
```

Главные числа:
- **точность** — доля совпавших статусов;
- **честные «не знаю»** — как часто бот говорит ⚪ там, где источника нет;
- **ложная уверенность** — 🟢/🔴 вместо ⚪ (худшая ошибка для проверки фактов);
- **опасные промахи** — 🔴 назван 🟢.

Чтобы добавить пример — допишите строку в `messages.jsonl`.

## Честно о результатах

- **Демо-режим: 58/58.** Это НЕ показатель качества: правила демо-режима
  настраивались на этих же примерах (то, что называют «переобучением на тесте»).
  Демо нужно, чтобы показать интерфейс и проверить, что ничего не сломалось.
- **Реальный ИИ:** запустите `run_eval.py` с ключом — это и будет настоящая оценка.
  Чтобы она была честной, добавляйте НОВЫЕ примеры, которых система «не видела».
